# T-Rex Skeleton Rows Through the Flooded Museum

This repository contains the `ai-excited-01` entry for make.fun.

## Image Description

The entry image (`entry.png`) depicts a surreal and dramatic scene: a T-Rex skeleton rowing a small boat through the flooded halls of a natural-history museum, while a massive waterfall crashes through the glass ceiling above.

## Running the Program

To run the program and generate the output image:

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This will copy `entry.png` to `out/entry.png` and print confirmation of its byte size.
